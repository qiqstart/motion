# docs/

Designs, proposals, research write-ups, decision records and meeting notes live here, not only in chat.

- File name: `docs/<topic>-YYYY-MM-DD.md`
- First line is a status header: `Status: current as of YYYY-MM-DD`, `Status: proposal`, or `Status: accepted`.
- Never rewrite history. When advice changes, add a new dated file and change the old file's first line to `Status: superseded by docs/<new-file>.md (YYYY-MM-DD)`.
- End each doc with a `## Decisions` section recording the owner's choices with dates.
- Link the doc from its issue or PR. Docs go in via PR like any other change.
