# MCP server

`/api/mcp` is a remote MCP endpoint for the signed-in studio. Tools: list_pages, read_page, search_pages, create_page, update_page, delete_page. A missing session gets 401.

The button in the sidebar copies a config that uses the current session token. Signing out ends that token. There is no separate agent password and no database change.

## Decisions
- 2026-11-21: Reuse the existing session cookie and bearer token. Do not add OAuth tables.
