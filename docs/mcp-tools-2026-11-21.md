# MCP tool behavior

Reading a page returns plain sentences, properties, and subpage links. A bad id or a missing page comes back as a tool error. Blank text does not append. Replace writes the new paragraphs only.

The session decision stays the same: no session on a real database is 401, and the copied config still uses the current session token.

## Decisions
- 2026-11-21: Tool failures stay inside the tool result so the agent can continue. They are not HTTP 500s.
